1. Dashboard DevOps & Vận Hành Hệ Thống

DevOps & SRE

Giám sát tài nguyên máy chủ và hiệu năng ứng dụng theo thời gian thực (RED Method).

Tính Năng Chi Tiết Trên Grafana:
  • CPU & RAM Node.js: Đo lường % CPU và dung lượng RAM tiêu hao theo thời gian thực.
  • Throughput (RPS): Tần suất yêu cầu / giây mà Web Server đang phục vụ.
  • Độ trễ phản hồi (Response Latency): Đo lường chính xác các phân vị P50, P95, P99.
  • Tỉ lệ lỗi HTTP Status: Phân loại chi tiết mã trả về 2xx, 4xx, 5xx.
  • Top Endpoints: Thống kê các API được gọi nhiều nhất (đơn hàng, thiết bị, giỏ hàng...).
  • Live Loki Logs Stream: Xem trực tiếp nhật ký ứng dụng và thông báo lỗi.

2. Dashboard Kiểm Định Chất Lượng & Test Tải (k6)

QA Testing

Cung cấp minh chứng số liệu kiểm thử hiệu năng phục vụ môn Kiểm định chất lượng phần mềm.

Tính Năng Chi Tiết Trên Grafana:
  • Người Dùng Ảo (Virtual Users - VUs): Theo dõi số lượng VUs đang đồng thời truy cập.
  • Đánh Giá Tiêu Chuẩn SLA: Tỉ lệ lỗi SLA (ngưỡng < 1%) và độ trễ SLA (P95 < 500ms).
  • Hiệu Năng Khi Tăng Tải: Quan sát khả năng chịu tải khi người dùng tăng dần từ 1 đến 50 VUs.
  • Phân Tích Điểm Nghẽn API: Đo đạc tốc độ xử lý của từng trang (Trang chủ, Chi tiết, Đặt hàng, Admin).
  • Báo Cáo Minh Chứng Đồ Thị: Xuất biểu đồ và bảng số liệu để đưa vào báo cáo đồ án.
Mở Trực Tiếp Dashboard QA Test (:3001)

Kích Hoạt Kịch Bản Kiểm Thử Tải QA (k6 Load Test Script)

Để quan sát biểu đồ nhảy số liệu thời gian thực trên Grafana, bạn hãy mở terminal PowerShell và chạy script k6 đi kèm dự án:

powershell -ExecutionPolicy Bypass -File monitoring/k6/run-test.ps1 Script tự động đẩy metrics vào Prometheus & Grafana
